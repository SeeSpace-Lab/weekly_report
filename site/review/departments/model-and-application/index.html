Cheap Probes Predict Expensive Training in 3D-CT Vision--Language Models

廉价 Probe 能否预测昂贵训练：3D CT VLM 的编码器与 Token 压缩筛选

论文用冻结视觉特征上的轻量 probe 排序编码器—压缩组合，初步与完整微调结果达到约 0.95 的相关性。

问题
3D CT VLM 同时选择视觉编码器、Token 压缩方法和预算会形成巨大的组合空间，逐个微调 LLM 的成本过高。
方法
作者构建覆盖编码器与压缩单元格的图像 grounding probe 基准，并用 scale-sanity 与 probe-separability 两道门检查属性尺度和可解码性。
结果
摘要报告已测单元格中廉价 probe 与昂贵微调排序约为 r=0.95，但作者明确将其解释为排序信号而非精确性能预测。
证据与局限
  • arXiv 官方摘要中的方法、验证门和 r≈0.95 初步结果

局限：结果仍是初步研究且只覆盖已测单元格；医学 3D CT 场景能否泛化到通用 VLM 尚未验证

部门意义

可把 probe 排序用于 Token 压缩预筛选，但最终候选仍需在目标任务、模型和预算上完整训练验证。

UltraViT: Latency-Optimized On-device Vision Encoder for Large Vision-Language Models

UltraViT：为端侧时延直接设计的大视觉语言模型编码器

UltraViT 用真实设备时延指导金字塔架构和异构 spatial mixer 组合，并配套两阶段生成式预训练。

问题
端侧 LVLM 压缩常集中在视觉 Token 和小语言模型，计算量显著的视觉编码器仍沿用面向服务器的单体结构。
方法
模型以设备实测时延设计宏块级金字塔结构，再通过密集蒸馏学习空间特征，并由容量混合的冻结 LLM 提供生成式语义监督。
结果
摘要称该设计相对 encoder-centric 基线获得更高准确率，并在设备端接近 1.7 倍速度；具体设备和全量表格仍需正文复核。
证据与局限
  • arXiv 官方摘要中的架构、训练方法和近 1.7 倍速度结果

局限：摘要未给出这里所需的完整设备、能耗与内存数据；宣称的 SOTA 需结合正文基线公平性判断

部门意义

模型应用组可把 encoder 本身列为压缩主变量，并以目标芯片实测时延而非 FLOPs 单独指导结构选择。

PathSelect: Sequential Token Selection for Whole Slide Pathology

PathSelect：面向全切片病理图像的序列式视觉 Token 选择

该方法把 WSI Token 剪枝改写为可学习的序列选择，在冻结 SlideChat 主干下训练路由器，推理时只保留硬 Top-K scorer。

问题
Gigapixel WSI 产生极长视觉序列，静态空间采样和免训练剪枝容易丢失分散但关键的病理证据。
方法
训练阶段用保方差噪声门、可微 Soft Top-K 和对角注意力去噪器传递梯度，推理阶段移除训练插件，由 scorer 和 Hard Top-K 自适应终止。
结果
摘要报告平均仅保留 44.86 个 Token、最大 K=128，在 SlideBench TCGA 上达到 74.00% 准确率，相对未压缩平均序列约减少 36.6 倍。
证据与局限
  • arXiv 官方摘要中的 SlideBench、Token 数和准确率数据

局限：验证集中在病理 WSI；摘要未提供不同 K 值下完整精度—时延曲线

部门意义

该训练—部署解耦思路适合迁移到遥感大图，但应重点验证稀疏小目标和跨尺度信息是否被 scorer 漏掉。

Mage-VL: An Efficient Codec-Native Streaming Multimodal Foundation Model

Mage-VL：利用视频编解码信息的流式多模态基础模型

Mage-VL 以运动矢量和残差能量选择动态区域，在 I/P 帧间编码信息丰富的 patch，使视觉 Token 消耗降低超过 75%。

问题
传统 VLM 对流式视频仍采用均匀采帧和高冗余视觉编码，离线推理能力强但实时感知效率不足。
方法
Mage-ViT 在 16×16 patch 粒度利用 codec 的运动与残差信号选择区域，模型再以轻量事件门和因果解码器组成双系统流式架构。
结果
摘要称 Mage-VL-4B 在静态任务匹配 Qwen3-VL-4B，视频和空间推理更强，墙钟推理最多加速 3.5 倍，并超过 15B Phi-4-reasoning-vision。
证据与局限
  • arXiv 官方摘要中的训练规模、Token 降幅和性能比较

局限：最高 3.5 倍是特定配置结果；需要正文核查编码器、分辨率和硬件对比较的影响

部门意义

这是压缩视频表征与 VLM 融合的优先复现对象，建议同时测 Token、端到端时延、任务精度和 codec 依赖。

DocAnnot -- Accelerating the Creation of Key Information Extraction Datasets with GenAI-Powered Auto-annotation

DocAnnot：用生成式 AI 加速文档关键信息抽取数据标注

DocAnnot 组合 LVLM 抽取、OCR 框定位和空间上下文匹配，将人工从逐项标注转为审核修正。

问题
文档 KIE 训练数据依赖耗时的人工标签，尤其在版式复杂和资源有限的场景中难以快速迭代。
方法
框架先由 LVLM 提取标签值，再用 OCR 获取文字和框，并通过 SICM 联合文本匹配、空间关系与距离完成标签—值对齐。
结果
摘要报告自动标注在 CORD 和 SROIE 上 F1 为 0.679 和 0.846；仅用自动标注训练的 LayoutLMv3 在 CORD 上为 0.6765。
证据与局限
  • arXiv 官方摘要中的 CORD、SROIE 和 LayoutLMv3 数据

局限：人工标注仍然更好；系统定位是减少人工工作量而非完全无人标注

部门意义

适合构建内部文档或遥感元数据的半自动标注流程，但质量门禁必须保留人工复核和抽样统计。

Visual Information Extraction from Documents via Classification-Guided Large Vision-Language Models

分类引导的大视觉语言模型文档信息抽取

该框架先判断文档类型，再以 ICL 动态注入任务知识，降低不同版式共用一个抽取器时的任务不确定性。

问题
视觉丰富文档版式差异和污损显著，顺序 OCR 流水线脆弱，而端到端专用模型又依赖大量版式特定标注。
方法
方法把文档分类与字段抽取解耦，基于分类结果动态构造 in-context prompt，使 Qwen2.5-VL-7B 在不同证件类型上执行零样本抽取。
结果
摘要报告 16 类真实投标证件上零样本 F1 为 86.43%，监督基线为 68.08%；可选领域微调进一步达到 93.65%。
证据与局限
  • arXiv 官方摘要中的 16 类数据、F1 与 NED 对比
  • 作者公开的代码和 Hugging Face 模型链接

局限：结果来自单一投标文档数据域；零样本提示可能依赖基础模型版本与提示模板

部门意义

可作为多类型业务文档和遥感产品元数据抽取基线，但跨域部署前要验证分类错误对后续抽取的级联影响。

Hallucinations Leave a Grounding Signature:Verifier-Guided Decoding for Selective Object Correction

幻觉留下 Grounding 指纹：验证器引导的选择性对象纠错

VGD 从注意力中识别对象级 Intrinsic Grounding Signature，只对高风险对象回滚 KV cache、抑制同义词并重新生成。

问题
输出概率反映语言合理性而非视觉支持，粗粒度幻觉抑制会同时缩短回答并损害真实对象覆盖。
方法
轻量验证器监测正在生成的对象提及，利用分布式有符号注意力模式判断 grounding 风险，高风险时回滚对应 KV 并局部再解码。
结果
摘要报告在 AMBER-G 的 rec90 设置下 CHAIR 降低 43.6% 且保留 99.6% grounded-object 覆盖，MSCOCO CHAIR_i/s 降低 37.0%/30.4%。
证据与局限
  • arXiv 官方摘要中的 CHAIR 与覆盖率结果

局限：当前证据集中在对象幻觉和 caption 类基准；注意力签名在其他架构和长链推理中的泛化仍需验证

部门意义

可将对象级验证器用于遥感和专业视觉 Agent 的输出安全层，但不能替代任务级事实核验。

StepX-Edge: An On-Device UI Vision-Language Model via Architecture-Training-Deployment Co-Design

StepX-Edge：架构—训练—部署协同设计的端侧 UI VLM

StepX-Edge 以 0.9B 参数、UI 专用视觉编码和分阶段训练结合 PTQ/QAT，在 Snapdragon 8 Gen5 上实现端侧运行。

问题
UI 理解同时要求 OCR、屏幕问答和元素定位精度，但移动芯片的计算、内存和功耗限制使常规模型难以部署。
方法
模型使用 UI-aware Layered Visual Encoding、渐进维度投影和五阶段课程训练，并按模块采用两阶段 PTQ 到 QAT 的差异化量化。
结果
摘要报告 W4A16+KV8 后在 Snapdragon 8 Gen5 上 TTFT 约 0.84 秒、解码 98 tok/s、峰值内存 1.4GB，量化精度损失控制在 1% 内。
证据与局限
  • arXiv 官方摘要中的基准与 Snapdragon 8 Gen5 实测指标

局限：作者表示将开源，当前需核实实际开放状态；UI 专用结果不直接代表通用多模态能力

部门意义

可用作小型 VLM 端侧协同设计案例，重点借鉴按模块量化和真实设备指标闭环。
