- 时间：2026-08-16T01:40:07+00:00
- 建议阅读：3 分钟

**中文标题：** Q-First：分离式解码中多数 Attention 先传 Query 即可

**Q-First 利用 attention 输出在 token 间可聚合的性质，把大多数 KV 拉取改成小得多的 query 发送与局部计算。**

分离式 LLM 解码若为每步把大量远端 KV 拉到计算节点，网络流量与尾延迟会随上下文增长，限制吞吐和弹性。
